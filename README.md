# yoshitaku-jp.github.io

yoshitaku-jp（YOSHIMURA Takuya）のポートフォリオサイト。Astro 製の静的サイトで、GitHub Pages に公開している。

- 日本語: `/`
- English: `/en/`

## セットアップ

```bash
npm install
npm run dev
```

| コマンド | 内容 |
| --- | --- |
| `npm run dev` | 開発サーバーを起動（http://localhost:4321） |
| `npm run build` | 型チェック（`astro check`）＋ `dist/` へのビルド |
| `npm run preview` | ビルド結果をローカルで確認 |
